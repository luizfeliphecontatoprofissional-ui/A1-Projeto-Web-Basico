# A1-Projeto-Web-Basico

Projeto acadêmico de desenvolvimento Front-end para Web, desenvolvido como uma loja virtual fictícia de produtos e acessórios de tecnologia.

O site reúne catálogo de produtos, ofertas, notícias e funcionalidades interativas.

## Funcionalidades

- Catálogo com 16 produtos e filtros por categoria e finalidade de uso.

- Página de ofertas e destaques.

- Sistema de favoritos com armazenamento em localStorage.

- Comparador de produtos com cálculo de soma, média e identificação do menor preço.

- Página de notícias sobre tecnologia.

- Formulário de contato com validação.

## Tecnologias utilizadas

- HTML5

- CSS3

- JavaScript

- Bootstrap 5

- Git & GitHub 

## Como executar

- Baixe o arquivo ByteNova.zip disponível neste repositório.

- Extraia o conteúdo.

- Abra o arquivo index.html no navegador.

O projeto pode ser executado localmente, sem necessidade de servidor.
